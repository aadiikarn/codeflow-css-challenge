# CODEFLOW — Design. Structure. Motion.

A modern responsive CSS showcase website created to demonstrate practical frontend and CSS skills including Flexbox, CSS Grid, responsive design, transitions, transforms, animations, and JavaScript interactions.

## Project Overview

CODEFLOW is a frontend CSS challenge project designed as an interactive showcase of modern CSS capabilities.

The project focuses on demonstrating structured layouts, responsive interfaces, visual effects, animations, and interactive components.

## Features

- Modern blue and black visual design
- Responsive desktop, tablet, and mobile layouts
- Dark and Light theme toggle
- Theme preference saved using LocalStorage
- Responsive mobile navigation
- Smooth scrolling navigation
- Active navigation highlighting
- Scroll reveal animations
- Flexbox showcase
- CSS Grid gallery
- CSS animation demonstrations
- CSS concepts showcase
- Responsive design demonstration
- Interactive hover effects
- Keyboard Escape support
- Semantic HTML structure

Mobile Navigation

Scroll Detection

Active Navigation
Intersection Observer detects the currently visible section and highlights its navigation link.

Reveal Animation

Smooth Scrolling

Design Approach

CODEFLOW uses a blue and black visual system focused on a modern developer-oriented aesthetic.

The design combines:
- Deep dark backgrounds
- Electric blue accents
- Soft blue gradients
- Subtle shadows
- Rounded cards
- Modern typography
- Motion-based interactions

The Light Theme provides a clean alternative using bright backgrounds, white cards, dark typography, and blue accents.
